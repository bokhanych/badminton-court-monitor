# Монитор свободных кортов «Минск-Арены»

Сервис проверяет [расписание услуги 148](https://saleframe.minskarena.by/service/148) и отправляет сообщение в Telegram, когда слот с началом в 18:00 или позже становится доступен для покупки. Проверяются все даты, опубликованные сайтом.

## Запуск

1. Создайте Telegram-бота через `@BotFather` и скопируйте токен.
2. Напишите боту любое сообщение. Узнайте `chat_id`, открыв `https://api.telegram.org/bot<ТОКЕН>/getUpdates` (поле `message.chat.id`).
3. Скопируйте настройки и заполните секреты: `cp .env.example .env`.
4. Выполните `docker compose up -d --build`, затем смотрите журнал: `docker compose logs -f monitor`.

При первом успешном опросе монитор только запоминает уже доступные слоты. Это исключает пачку старых уведомлений. Все последующие переходы из «недоступен» в «доступен», а также новые доступные вечерние слоты, будут отправлены в Telegram.

## Как работает мониторинг

- Бот запрашивает свежее расписание каждые 60 секунд (`CHECK_INTERVAL_SECONDS=60`).
- Проверяются все будущие даты, которые в данный момент опубликованы на сайте «Минск-Арены»; фиксированного ограничения по числу дней нет.
- Учитываются слоты с началом в 18:00 или позже (`EVENING_START=18:00`) в часовом поясе `Europe/Minsk`.
- Слоты, до начала которых осталось 30 минут или меньше, не учитываются — это соответствует ограничению покупки на сайте.
- Уведомление отправляется только при появлении новой доступности. Все одновременно появившиеся слоты одной даты объединяются в одно сообщение.
- Состояние хранится между перезапусками, поэтому уже известные доступные слоты повторно не отправляются.

Проверить Telegram без ожидания корта: `docker compose run --rm monitor python -m app --test-notification`.

Вручную запросить и отправить в Telegram актуальные вечерние слоты за все будни следующей календарной недели:

```bash
docker compose run --rm monitor python -m app --weekdays-next-week
```

Команда всегда берёт период с ближайшего следующего понедельника по пятницу включительно. На каждый день отправляется отдельное сообщение; если свободных слотов нет, это также будет указано в сообщении. Перед ручным запросом после изменения кода пересоберите образ: `docker compose build`.

## Настройки

| Переменная | По умолчанию | Назначение |
|---|---:|---|
| `TELEGRAM_BOT_TOKEN` | — | токен бота (обязательно) |
| `TELEGRAM_CHAT_ID` | — | ID пользователя/группы (обязательно) |
| `CHECK_INTERVAL_SECONDS` | `60` | интервал проверок |
| `EVENING_START` | `18:00` | минимальное время начала слота |
| `INITIAL_NOTIFY` | `false` | отправить доступные слоты и при первом запуске |
| `TIMEZONE` | `Europe/Minsk` | часовой пояс расписания |
| `REQUEST_TIMEOUT_SECONDS` | `20` | таймаут HTTP-запроса |
| `LOG_LEVEL` | `INFO` | уровень логирования |

Состояние хранится в volume `monitor-data`. Намеренно сбросить его: `docker compose down -v`.

Тесты: `python -m unittest discover -s tests -v`.
